# 小姐姐放映厅 🎬

随机小姐姐短视频：十源加权轮换（近期优先）、去重不重样、账号系统（ID+密码）、收藏含原始信息、无水印下载、**多候选择优 + 码率自学习**（更高清、更流畅）。

## 打开方式

**推荐：双击 `启动网站.bat`**（完整功能：收藏 / 历史 / 下载 / 原始信息解析）
自动启动本地服务并打开浏览器（http://127.0.0.1:8899）。

直接双击 `index.html` 也能看（直连模式），但收藏 / 下载需要解析视频直链，会提示先启动本地服务。

## 功能

- 🎲 **十源加权轮换**：青春 / 甜妹（权重高，池大且新）、热点 / 热舞 / 街拍、古装 / COS、精选 / 合集 / 站长
- 🚫 **不重样**：本地记录最近 1500 条看过的直链，解析出重复自动换源重取（最多 5 次）
- ⚡ **两段式秒开**：切换后立即解析下一条直链（零带宽成本），当前视频缓冲达标后才拉下一条——预载永不抢带宽；按近期加载中位数自适应预载阈值与超时兜底
- 🛡️ **多重容错**：服务端解析先验活（死链直接换）；**坏源自学习剔除**（某源连续拿不到可用直链自动降权，积累足够成功样本后自动复活）；自适应超时自动踢出；解析失败重试换源；解析堆积自动降级直连；坏直链触发服务端扩容重试（最多 3 轮）
- 🎚 **多候选择优（更高清）**：服务端并发拉取多个分类，探测每条视频的真实分辨率/时长/码率（解析 MP4 头部），挑码率最高的一条返回。实测并发 3 条比单条中位码率提升约 46%
- 📈 **码率自学习**：按每条实测码率给各源加权（清晰的多刷、糊的少刷），总能推出更清晰的源；信息栏显示实时分辨率 + 码率
- 🎮 **画质档位**：账号面板可切换 流畅/均衡/高清/极致——档位越高并发候选越多、码率门槛越高，画面更清晰（代价是切换解析略慢零点几秒）
- 🛡️ **帧率守护**：实测持续掉帧会自动精简背景装饰（辉光/毛玻璃），把合成带宽还给视频，保播放流畅
- 📣 **抖音近期源（可选）**：到 [istero.com](https://api.istero.com) 免费注册拿 Token，填入账号面板后约四成视频来自抖音近期热门小姐姐
- ↩️ **回看**：回到上一条，保留播放位置瞬间恢复
- ❤️ **收藏**：查看原始信息——博主 ID、发布时间、原始页面链接（快手）、视频直链、时长分辨率；面板内点击回放
- 🕘 **历史记录**：自动记录最近 100 条，点击回放，可清空
- 👤 **本地账号**：ID + 密码（SHA-256 哈希存储），收藏 / 历史 / 点赞按账号分开，刷新保持登录
- ⬇️ **下载**：前端直接拉流保存 `小姐姐视频_发布时间.mp4`（无水印）
- 📱🖥️ **自适应**：电脑居中卡片 + 手机全屏，功能键在视频下方

**快捷键**：`↑` 下一条 · `↓` 回看 · `空格` 暂停 · `R` 随机 · `M` 静音 · `L` 点赞 · `F` 收藏 · `D` 下载 · 双击画面点赞

## 已知限制

- 免费采集 API 的内容多采集于 2023~2024 年，已按池子做「近期优先」；真正的当日抖音热榜需付费数据服务（已预留 istero Token 接入口，注册免费即可启用其一）。**画质择优基于可用源内的码率挑选**，不改变源本身的清晰度上限。
- 账号纯本地存储：换电脑 / 清浏览器数据后收藏不迁移；密码遗失无法找回。

## 部署

支持 **Docker**（VPS/NAS/群晖）、**Render/Railway 云平台一键**、**VPS systemd**、**本地 Windows 常驻**、**纯静态托管（受限模式）** 五种方案，含公网访问口令保护说明——见 [DEPLOY.md](DEPLOY.md)。

**Docker 部署**：

```bash
# 首次部署
git clone https://github.com/dll315/beauty-reels.git && cd beauty-reels
docker compose up -d --build        # 访问 http://IP:8899

# 更新到最新版
git pull
docker compose up -d --build        # 或：docker build -t beauty-reels . && docker rm -f beauty-reels && docker run ...

# 换端口（两种任选）
docker run -d -p 9000:8899 beauty-reels                    # ① 只改宿主机映射
docker run -d -p 9000:9000 -e PORT=9000 beauty-reels       # ② 连容器内部端口一起改
PORT=9000 docker compose up -d --build                     # compose 方式
```

## 文件结构

```
beauty-reels/
├── index.html        # 全部前端功能（单文件）：档位选择 / 码率自学习 / 帧率守护 / 性能优化
├── server.py         # 静态托管 + 多候选择优直链解析（并发探测码率，零依赖）
└── 启动网站.bat       # 一键启动
```

**画质择优说明**：server.py 默认并发拉取 3 个分类各一条直链，用 Range 请求渐进读取 MP4 头部解析出 分辨率/时长/码率（无需下载整条视频），再按码率挑最优返回。可用环境变量调整：`CANDIDATES`（并发候选数）、`MIN_KBPS`（最低码率门槛）、`PROBE=0`（关闭探测、退化为旧版随机直取）、`PROBE_CACHE`（探测缓存秒数）。

**坏源自学习**：免费源偶发失效（如某个分类返回 404 死链）。前端会记录每个源的成功/失败次数，失败比例高的源自动降权剔除（不再被随机选中），从源头规避加载失败；服务端在候选失效时也会自动扩容重试，双保险确保流畅播放。
